# PROJETO — APLICATIVO MOBILE DE TRADUÇÃO

## Objetivo geral

Desenvolver um aplicativo mobile para Android e iOS capaz de traduzir:

- Inglês → Português do Brasil
- Espanhol → Português do Brasil

O aplicativo também deverá permitir tradução através da voz.

## Tecnologias principais

Frontend:
- Flutter
- Dart

Backend:
- Node.js
- Express
- TypeScript

Integrações:
- API de tradução
- Speech-to-Text
- Text-to-Speech

IMPORTANTE:

Este projeto NÃO terá:

- banco de dados
- PostgreSQL
- SQLite
- histórico
- favoritos
- cadastro
- login

O aplicativo não deverá armazenar as traduções realizadas.
